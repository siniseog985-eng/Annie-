# Annie — GitHub Pages 음악 앱
1. ZIP 안의 모든 파일과 폴더를 GitHub 저장소 최상위(root)에 업로드합니다.
2. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
3. 배포된 HTTPS 주소를 Safari에서 열고 공유 → 홈 화면에 추가합니다.

Annie 설정: 블랙 테마, 사용자 사진 배경, 음악 이펙트 켜기/끄기.
iPhone 홈 화면 아이콘: `apple-touch-icon.png`가 저장소 최상위에도 포함되어야 합니다.
설정과 배경 사진은 현재 기기에 저장됩니다.
